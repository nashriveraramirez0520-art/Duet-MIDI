# Firmware

Firmware has not been implemented yet, and the build platform has not been selected.

The first milestone is a minimal USB MIDI example on the chosen controller. Add one touch pad, then all eight pads, mode switching, buttons, the encoder, the slider, and RGB feedback.

See [the design plan](../docs/design-plan.md) for note handling and validation requirements. Build and flashing instructions will be added with the actual source.
