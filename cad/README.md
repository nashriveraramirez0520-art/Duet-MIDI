# Enclosure CAD

V1 is modeled in Onshape, with a bottom case, removable lid, four button extensions, an encoder knob, and a slider cap. I also left a pocket for a separate acrylic bottom window so part of the board can stay visible.

- [Assembly STEP (gzip)](enclosure-v1/enclosure-v1-assembly.step.gz)
- [Individual STEP parts](enclosure-v1/step/)
- [Printable STL parts](enclosure-v1/stl/)
- [Dimensions, mounting notes, and fit checks](enclosure-v1/README.md)

The files are ready for fit-test prints, but the enclosure has not been physically tested. Start with one button, the knob, and the slider cap. The acrylic window is separate from the eight printed parts.
